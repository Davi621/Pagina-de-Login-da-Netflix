## 📋 Sobre o Projeto

Este projeto é uma recriação da página de login da Netflix, desenvolvido com o objetivo de praticar e demonstrar habilidades em desenvolvimento web front-end. O foco está na implementação de uma interface responsiva, validação de formulários e aplicação de boas práticas de código.

## 🚀 Tecnologias Utilizadas

### HTML5
**Propósito de Prática:**
- Estruturação semântica de páginas web
- Utilização correta de tags para formulários (`<form>`, `<input>`, `<label>`)
- Organização hierárquica de elementos
- Acessibilidade através de atributos apropriados

**Como Funciona:**
O HTML5 é a linguagem de marcação que define a estrutura e o conteúdo da página. No projeto, é utilizado para criar a estrutura do formulário de login, incluindo campos de entrada para email/telefone e senha, botões de ação e elementos de navegação.

### CSS3
**Propósito de Prática:**
- Design responsivo com media queries
- Flexbox e Grid Layout para posicionamento
- Estilização avançada de formulários
- Criação de efeitos visuais (sombras, transições, gradientes)
- Aplicação de metodologias como BEM ou CSS Modules

**Como Funciona:**
O CSS3 é responsável pela apresentação visual da página. Define cores, tipografia, espaçamentos, layouts e comportamentos visuais. Utiliza técnicas modernas para garantir que a interface seja responsiva e funcione bem em diferentes tamanhos de tela, replicando fielmente o design característico da Netflix.

### JavaScript
**Propósito de Prática:**
- Manipulação do DOM (Document Object Model)
- Validação de formulários em tempo real
- Event listeners e manipuladores de eventos
- Lógica condicional e controle de fluxo
- Feedback visual ao usuário
- Boas práticas de código limpo e organizado

**Como Funciona:**
O JavaScript adiciona interatividade à página. Implementa validações de entrada (verificando se o email é válido, se os campos estão preenchidos), fornece feedback visual ao usuário (mensagens de erro, mudanças de estado dos campos), e controla o comportamento dinâmico da interface, como mostrar/ocultar senha e responder a ações do usuário.

## 💡 Funcionalidades

- ✅ Validação de email em tempo real
- ✅ Validação de senha com requisitos mínimos
- ✅ Feedback visual de erros
- ✅ Design responsivo (desktop, tablet, mobile)
- ✅ Animações e transições suaves
- ✅ Alternância de visibilidade da senha
- ✅ Interface fiel ao design original da Netflix

Este projeto foi desenvolvido para praticar:

1. **Estruturação HTML Semântica**: Organizar conteúdo de forma lógica e acessível
2. **Estilização CSS Avançada**: Criar interfaces modernas e responsivas
3. **JavaScript Vanilla**: Implementar funcionalidades sem dependência de frameworks
4. **Validação de Formulários**: Garantir entrada de dados válida
5. **Responsividade**: Adaptar layout para diferentes dispositivos
6. **Boas Práticas**: Código limpo, comentado e bem estruturado

## 🖥️ Como Executar o Projeto

1. Clone este repositório:
```bash
git clone https://github.com/Davi621/Pagina-de-Login-da-Netflix.git
```

2. Navegue até a pasta do projeto:
```bash
cd Pagina-de-Login-da-Netflix
```

3. Abra o arquivo `index.html` em seu navegador preferido

Ou simplesmente arraste o arquivo `index.html` para uma janela do navegador.
